## Steps:

#### 1) Install RustDesk via Flatpak
```
sudo apt update && sudo apt install flatpak -y
flatpak remote-add --if-not-exists flathub https://flathub.org
flatpak install flathub com.rustdesk.RustDesk
```
#### 2) Run RustDesk via Flatpak

```
flatpak run com.rustdesk.RustDesk
```

#### AppArmor Bug Fix:
A known issue where fusermount3 will lack the permission needed for Flatpak to work. Run this command to disable the conflicting profile.


##### To disable fusermount3:
```
sudo ln -s /etc/apparmor.d/fusermount3 /etc/apparmor.d/disable/
sudo apparmor_parser -R /etc/apparmor.d/fusermount3\
```

##### To re-enable the security profile:
```
sudo rm /etc/apparmor.d/disable/fusermount3
sudo apparmor_parser -r /etc/apparmor.d/fusermount3
```

#### **DISCLAIMER**:
Im only disabling the AppArmor profile because im running a version of Kubuntu thats yet to have a fix for this bug. Apply due diligence and research how your machine will react to these commands let alone any SUDO commands. DO NOT disable fusermount3 with any production machine/systems, I am not responsible for any deployments you made - or will make - with this command without proper research and understanding of your underlying system. 

I'm using these commands in an isolated test machine... I have yet ran into issues/other gotchas up to this point.
