# Overview
During February I documented several development and learning sessions focused on cloud infrastructure, networking concepts, cybersecurity fundamentals, and development tooling. The logs track both conceptual study and practical troubleshooting while expanding familiarity with platforms like AWS and tools used in modern development workflows.

Throughout these sessions I explored network architecture, database services, security monitoring, and project management tooling, while also documenting troubleshooting processes and planning future areas of study.

   - Explored AWS database services, including relational database platforms such as PostgreSQL, Oracle, and MySQL
   - Reviewed AWS storage monitoring and metrics for tracking infrastructure performance
   - Studied network deployment lifecycle stages from planning and hardware installation to configuration, testing, and documentation
- Cybersecurity Concepts
  - Reviewed topics from the Security+ SY0-701 certification, including: Industrial Control Systems (ICS) and SCADA environments, Security Information and Event Management (SIEM) and Business partner agreements and service level agreements.
