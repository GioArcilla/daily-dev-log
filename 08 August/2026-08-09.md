## AAA Security Framework

|Principle |Description|
|---|---:|
|Authentication| The process of verifying the identity of a user or system|
|Authorization| Determines what resources and actions the user is permitted to access or perform|
|Accounting| This process involves tracking user activity and resource usage within the system|
